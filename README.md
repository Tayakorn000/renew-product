# Renew Product

โปรแกรมต่ออายุสินค้า Facebook Marketplace + ตอบแชทลูกค้าอัตโนมัติ (Tkinter + Selenium)

## Build .exe (Windows)

ต้องมี Python ก่อน แล้วรันตามนี้:

```
git clone https://github.com/Tayakorn000/renew-product.git
cd renew-product
pip install selenium undetected-chromedriver psutil pywin32 pyinstaller
pyinstaller --onefile --windowed --name "Renew Product" "Renew Product.py"
```

exe ออกที่ `dist\Renew Product.exe`

(`psutil` กับ `pywin32` ต้องลงด้วย โปรแกรม import ในฟังก์ชัน ไม่ลงก็ build ผ่านแต่ปิด Chrome ตอนออกโปรแกรมไม่ได้)

แก้โค้ดรอบหน้า ไม่ต้อง clone ใหม่ แค่:

```
git pull
pyinstaller --onefile --windowed --name "Renew Product" "Renew Product.py"
```

เครื่อง Windows ที่ใช้ build (`desktop-k0b7rmq` ใน Tailscale) ไม่มี git ลงไว้ ก็ scp ไฟล์ไปแทน:

```
scp "Renew Product.py" telegram_default.py "tayak@100.123.73.107:C:/build/Renew Product/"
ssh tayak@100.123.73.107 'cd /d "C:\build\Renew Product" && pyinstaller --noconfirm --onefile --windowed --name "Renew Product" "Renew Product.py"'
scp "tayak@100.123.73.107:C:/build/Renew Product/dist/Renew Product.exe" ~/Downloads/
```

(path ปลายทางของ scp ต้องใช้ `/` ไม่ใช่ `\`)

### เครื่อง Windows ปิดอยู่ build บน winserver แทน

Linux build exe ของ Windows ตรงๆ ไม่ได้ `Dockerfile.wine` เลยลง Python ของ Windows (จาก python.org) ไว้ใต้ Wine ใน Docker
image `renew-winbuild` สร้างไว้บน winserver แล้ว (ราว 5GB) รอบหน้าข้ามบรรทัด `docker build` ได้ เว้นแต่แก้ `Dockerfile.wine`

```
ssh localhost@100.97.191.26 'mkdir -p ~/build/renew-product'
scp Dockerfile.wine "Renew Product.py" telegram_default.py localhost@100.97.191.26:build/renew-product/
ssh localhost@100.97.191.26 'cd ~/build/renew-product && docker build -f Dockerfile.wine -t renew-winbuild . && docker run --rm -v "$PWD:/src" renew-winbuild'
scp "localhost@100.97.191.26:build/renew-product/dist/Renew Product.exe" ~/Downloads/
ssh localhost@100.97.191.26 'rm -rf ~/build/renew-product'
```

บรรทัดสุดท้ายห้ามข้าม ในโฟลเดอร์นั้นมี `telegram_default.py` ที่มี token อยู่

เพิ่มไลบรารีใหม่ในโค้ด ต้องเพิ่มในบรรทัด `pip install` ของ `Dockerfile.wine` ด้วย
exe ที่ได้ไม่มีไฟล์ของ Wine ปน (เทียบ DLL กับตัวที่ build จาก Windows แล้วตรงกัน) เปิดใต้ Wine ได้
แต่ส่วนที่เปิด Chrome ลองใต้ Wine ไม่ได้ ต้องลองบน Windows จริง

## อัปเดตอัตโนมัติ

exe เปิดขึ้นมาจะไปดูไฟล์ `Renew Product.py` บน GitHub (branch main) ถ้าเลข `APP_VERSION` ในนั้นมากกว่าตัวที่ฝังมาใน exe
มันโหลดไฟล์นั้นมารันแทน ลูกค้าไม่ต้องรับ exe ใหม่ เราไม่ต้อง build ใหม่ เลขเวอร์ชันดูได้ที่หัวหน้าต่าง (`v2`)

ปล่อยของใหม่ให้ลูกค้า:

1. แก้โค้ด แล้วเพิ่มเลข `APP_VERSION` ขึ้น 1
2. commit แล้ว push ขึ้น main
3. ลูกค้าปิดโปรแกรมแล้วเปิดใหม่ (GitHub ใช้เวลาราว 5 นาทีกว่าไฟล์ใหม่จะขึ้น)

push โดยไม่เพิ่มเลข = เครื่องที่โหลดเลขนั้นไปแล้วไม่โหลดซ้ำ แต่เครื่องที่เพิ่งลง exe หรือยังไม่เคยโหลด จะได้ของบน main ไปเลย
งานที่ยังไม่เสร็จอย่า push ขึ้น main ทำใน branch แยกแล้วค่อย merge ตอนพร้อมปล่อย

- ถอยเวอร์ชันด้วยการลดเลขไม่ได้ ของใหม่พังให้แก้แล้วเพิ่มเลขขึ้นอีก (หรือเอาโค้ดเก่ามา push ด้วยเลขที่สูงกว่า)
- เช็คแค่ตอนเปิดโปรแกรม เปิดค้างไว้ไม่อัปเดตเอง
- ไฟล์ที่โหลดมาเก็บเป็น `renew_update.py` ข้าง exe เน็ตล่มรอบหน้าก็ยังได้ตัวใหม่
- ตัวใหม่เปิดไม่ขึ้น โปรแกรมถอยไปใช้ตัวที่ฝังมาใน exe เอง
- ต้อง build exe ใหม่แค่ 2 กรณี: โค้ดใหม่ใช้ไลบรารีที่ exe ไม่ได้ฝังมา หรือเปลี่ยนบอทที่ฝังมา (`telegram_default.py`)
- รันจาก `.py` ตรงๆ ไม่อัปเดตตัวเอง ได้โค้ดในเครื่องเสมอ
- ใครที่ push ขึ้น repo นี้ได้ = รันโค้ดบนเครื่องลูกค้าได้ ดูแลบัญชี GitHub ให้ดี

## แจ้งเตือน Telegram

เวลามีลูกค้าทักเข้ามา โปรแกรมยิงแจ้งเตือนเข้า Telegram ได้ บอกว่ามาจากเฟสไหน สินค้าอะไร ตอบไปหรือยัง

exe ที่ build จากเครื่องที่มีไฟล์ `telegram_default.py` จะมีบอทติดมาในตัว เปิดมาช่อง Token/Chat ID มีค่าอยู่แล้ว
ไฟล์นั้น gitignore ไว้ (repo นี้ public ห้ามมี token) ถ้า clone มา build เองจะไม่มี ต้องกรอกเอง:

```python
# telegram_default.py
TELEGRAM_TOKEN = "123456:AA..."
TELEGRAM_CHAT_ID = "7017153301"
```

ค่าที่กรอกในโปรแกรมชนะค่าที่ฝังมา เปลี่ยนเป็นบอทตัวเองได้ตลอด

### เพิ่มคนรับแจ้งเตือน

ใครอยากได้แจ้งเตือน ทักบอทใน Telegram 1 ข้อความ (กด Start ก็นับ) โปรแกรมเพิ่มให้เอง ไม่ต้องหา Chat ID
อยากให้เข้ากลุ่ม ก็ดึงบอทเข้ากลุ่ม กลุ่มนั้นถูกเพิ่มเองเหมือนกัน

โปรแกรมเช็คคนใหม่ 3 จังหวะ: ตอนเปิดโปรแกรม ตอนกด "บันทึก + ทดสอบส่ง" และทุกครั้งที่มีแจ้งเตือนลูกค้าทัก
เพิ่มแล้วทุกคนได้ข้อความ `เพิ่ม <ชื่อ> (<เลข>) เข้ารับแจ้งเตือนแล้ว` และเลขไปโผล่ในช่อง Chat ID (หลายแชทคั่นด้วย `,`)

- Telegram เก็บข้อความที่ทักบอทไว้แค่ 24 ชม. ทักแล้วโปรแกรมต้องได้เช็คภายในนั้น ไม่งั้นทักใหม่อีกรอบ
- แต่ละเครื่องเก็บรายชื่อของตัวเอง เครื่องไหนเปิดโปรแกรมอยู่ เครื่องนั้นเพิ่ม
- เอาคนออก: ลบเลขของเขาออกจากช่อง Chat ID แล้วกดบันทึก (เขาทักบอทมาใหม่เมื่อไหร่ก็ถูกเพิ่มกลับ)
- ใครเจอบอทแล้วทักเข้ามาก็ถูกเพิ่มหมด ไม่มีรหัสกัน เห็นชื่อแปลกในข้อความ "เพิ่ม ..." ให้ลบออก

ใช้บอทตัวเอง: ทัก [@BotFather](https://t.me/BotFather) พิมพ์ `/newbot` ตั้งชื่อบอท ได้ Token มากรอกในช่อง Telegram Token
(ช่องอยู่ใต้หัวข้อตอบแชทลูกค้าอัตโนมัติ) ทักบอทตัวใหม่ 1 ข้อความ แล้วกดบันทึก + ทดสอบส่ง

## ตอบแชทอัตโนมัติ (รวมลูกค้าที่ตอบไปแล้ว)

ลูกค้าทักมาครั้งแรก โปรแกรมจับคู่ชื่อประกาศกับชื่อโฟลเดอร์สินค้า แล้วส่งข้อมูลหลักให้

แถว "ตอบออโต้ด้วย:" มีช่องติ๊ก 3 อัน (แชทหลัก / รีวิวสินค้า / รูปภาพเพิ่มเติม) เลือกได้ว่าจะให้ตอบออโต้ด้วยอะไรบ้าง
ค่าเริ่มต้นติ๊กแค่ **แชทหลัก** — ทักครั้งแรกได้ข้อมูลสินค้า ทักกลับมาถามอะไรแค่เด้ง Telegram ไม่ตอบให้
เพราะลูกค้าถาม "จ่ายปลายทางได้มั้ย" แล้วโดนยิงรีวิวกลับ มันไม่ใช่คำตอบ

ติ๊กรีวิวสินค้า/รูปภาพเพิ่มเติมเพิ่ม ถ้าอยากให้ส่งต่อเองตอนลูกค้าทักกลับมา (รีวิวก่อน รอบถัดไปรูปเพิ่มเติม)
โฟลเดอร์ไหนไม่มีไฟล์หรือเอาติ๊กออก มันข้ามไปอันถัดไป ติ๊กแล้วมีผลรอบสแกนถัดไปเลย ไม่ต้องกดหยุด

ปุ่มส่งด้วยมือยังใช้ได้ทุกกรณี กดแล้วระบบออโต้จะไม่ส่งโฟลเดอร์นั้นซ้ำ

แจ้งเตือน Telegram แปะข้อความที่ลูกค้าพิมพ์มาด้วย (`ลูกค้าพิมพ์: จ่ายปลายทางได้มั้ย`) อ่านจาก preview ในหน้ารายการแชท
ข้อความยาวจะโดน Facebook ตัดท้ายด้วย … ถ้าล่าสุดเป็นข้อความของเราเองจะไม่แปะบรรทัดนี้

## ต่ออายุสินค้าไปด้วยระหว่างเฝ้าแชท

กดปุ่มต่ออายุกับปุ่มตอบแชทพร้อมกันไม่ได้ (โปรแกรมล็อคไว้) เพราะ Chrome โปรไฟล์เดียวเปิดซ้อน 2 ตัวไม่ได้
ถ้าเปิดซ้อนโปรไฟล์จะพัง ต้องล็อกอินใหม่ทุกเฟส

แถว "ต่ออายุด้วย:" ติ๊ก **ต่ออายุสินค้าไปด้วยระหว่างเฝ้าแชท ทุก [30] นาที** แทน
ติ๊กแล้วแต่ละเฟสจะสลับเอง: สแกนแชท → ไปหน้าต่ออายุ กดต่อจนหมด → กลับมาสแกนแชทต่อ ใช้ Chrome ตัวเดิมตลอด
กดเริ่มรอบแรกมันต่ออายุให้เลย แล้วนับไปอีก 30 นาทีถึงต่อรอบถัดไป

ติ๊ก/แก้ตัวเลขนาทีแล้วมีผลรอบถัดไปเลย ไม่ต้องกดหยุดแล้วเริ่มใหม่ ช่องนาทีเว้นว่างหรือพิมพ์มั่วจะกลับเป็น 30
กดหยุดระหว่างมันกำลังต่ออายุอยู่ มันเลิกกลางคันแล้วปิด Chrome ไม่ต้องรอต่อจนหมดลิสต์

หมายเหตุ: มันดูแค่ว่ามีข้อความใหม่เข้ามา ไม่ได้เข้าใจว่าลูกค้าพูดอะไร ลูกค้าตอบ "ไม่สนใจครับ" ก็ได้รีวิวไปด้วย
และรอบสแกนแรกหลังอัปเดตโปรแกรม มันจะเก็บข้อมูลเป็นฐานเทียบก่อน 1 รอบ ยังไม่ส่งอะไรให้ประวัติเก่า
